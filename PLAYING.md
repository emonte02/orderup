# Play Order Up!! To Go

[**▶ Play on GitHub Pages**](https://emonte02.github.io/orderup/?v=1c2b0ec763c099b0)

Use desktop Chrome. Open the link and click **Start game**. All game files download automatically; you do not need to provide an APK or OBB. The first download is about 187 MB, and the progress bar shows how much has loaded.

Keep the tab selected during startup. The optimized build reaches the menu in about 10–11 seconds on the development Mac once the game files are available. First-time downloading adds time according to your connection. The game fills the browser window; **Full screen** hides browser controls.

Click and drag with the left mouse button. Right-click or press Escape to go back or pause. The original tutorial teaches cooking gestures. Use a quick mouse flick for the Ravioli cutter’s arrow prompt. To plate food from an oven or assistant icon, select the ready food first, then click the plate button.

During the introductory Burger Face tutorial, **Skip tutorial** takes you to the world map and remembers your choice on this browser. Future introductory tutorials are skipped automatically. Use **Tutorial: skip** beside Full screen to switch back to **Tutorial: play** for the next new game. This preference survives a new game and reloads; clearing site data removes it. Other cooking tips and minigame instructions still appear.

Progress saves in this browser. Use the same browser and address, then choose **Continue**. Closing during a shift returns to the latest original save rather than the exact cooking frame. GitHub Pages and the local launcher have separate saves. Clearing site data removes saves.

The optimized build averaged 38–49 fps in measured restaurant kitchens on the development M5 Max Mac. Speed depends on your computer and browser; occasional asset-loading stalls remain. Retired online purchases and leaderboards are unavailable.

## Existing Mac launcher

Double-click **Play Order Up.command** in the original workspace. It opens Chrome and uses the existing local game files. Leave the launcher window open while playing, or open http://127.0.0.1:8147 if it is already running. Reopen the launcher after a reboot. Files preload automatically; click **Start game** once for sound.

A clean checkout can instead use the complete-build commands in [README.md](README.md).
