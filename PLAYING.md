# Play Order Up!! To Go

[**▶ Play on GitHub Pages**](https://emonte02.github.io/orderup/?v=1c2b0ec763c099b0)

Use desktop Chrome. Open the link; the game starts automatically. All game files download automatically; you do not need to provide an APK or OBB. The first download is about 187 MB. Game files are cached on this device for later visits; only changed, missing, or damaged files download again. The progress bar covers loading and engine preparation, reaching 100% when the game opens. Sound starts with your first tap or keypress if autoplay is blocked.

Keep the tab selected during startup. The optimized build reaches the menu in about 10–11 seconds on the development Mac once the game files are available. First-time downloading adds time according to your connection. The game fills the browser window.

Click and drag with the left mouse button. Right-click or press Escape to go back or pause. The original tutorial teaches cooking gestures. Use a quick mouse flick for the Ravioli cutter’s arrow prompt. To plate food from an oven or assistant icon, select the ready food first, then click the plate button.

Once the introductory Burger Face tutorial starts, **Skip Tutorial** appears over the game. Click it to finish the tutorial and go to the world map. Your choice is remembered on this browser, so future introductory tutorials are skipped automatically.

Progress saves in this browser. Use the same browser and address, then choose **Continue**. Closing during a shift returns to the latest original save rather than the exact cooking frame. GitHub Pages and the local launcher have separate saves. Clearing site data removes saves and cached game files. Browsers can also evict the asset cache when storage is low; if storage is unavailable, the game still plays but may download again.

The optimized build averaged 38–49 fps in measured restaurant kitchens on the development M5 Max Mac. Speed depends on your computer and browser; occasional asset-loading stalls remain. Coin purchases are simulated locally without payment processing; retired leaderboards are unavailable.

## Existing Mac launcher

Double-click **Play Order Up.command** in the original workspace. It opens Chrome and uses the existing local game files. Leave the launcher window open while playing, or open http://127.0.0.1:8147 if it is already running. Reopen the launcher after a reboot. Files load and the game starts automatically; tap or press a key to enable sound if needed.

A clean checkout can instead use the complete-build commands in [README.md](README.md).
