# Play Order Up!! To Go

[**▶ Play on GitHub Pages**](https://emonte02.github.io/orderup/)

Use desktop Chrome. On your first visit, choose the Order Up!! To Go 1.65 APK and both version 13 OBB files together, then click **Start game**. They are read locally, never uploaded. Leave **Remember game files in this browser** checked to skip selection next time. If browser storage is unavailable, you can still play by selecting the files each visit.

The three files are `orderup-1.65.apk`, `main.13.com.svsgames.orderup.obb`, and `patch.13.com.svsgames.orderup.obb`. On the development Mac they are in `originals/`. The unrelated `order-up-to-go.apk` in the workspace root is not the game.

Keep the tab selected during startup and allow up to two minutes. The game fills the browser window; **Full screen** hides browser controls.

Click and drag with the left mouse button. Right-click or press Escape to go back or pause. The original tutorial teaches cooking gestures. Use a quick mouse flick for the Ravioli cutter’s arrow prompt. To plate food from an oven or assistant icon, select the ready food first, then click the plate button.

Progress saves in this browser. Use the same browser and address, then choose **Continue**. Closing during a shift returns to the latest original save rather than the exact cooking frame. GitHub Pages and the local launcher have separate saves. Clearing site data removes saves and remembered files.

Busy kitchens currently run around 20 frames per second on the development Mac. Retired online purchases and leaderboards are unavailable.

## Existing Mac launcher

Double-click **Play Order Up.command** in the original workspace. It opens Chrome and uses the existing local game files. Leave the launcher window open while playing, or open http://127.0.0.1:8147 if it is already running. Reopen the launcher after a reboot. Files preload automatically; click **Start game** once for sound.

A clean checkout can instead use the static-player commands in [README.md](README.md).
